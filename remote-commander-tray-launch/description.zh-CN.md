标题：你也在用 Desktop Commander Remote 吗？

在 Windows 上用 Desktop Commander Remote，就得一直开着一个 PowerShell 窗口，一关电脑就掉线。
Remote Commander Tray 帮你在后台运行它，不留黑窗口，只在右下角托盘留一个状态图标：登录即启动，崩了自己重启，平时不打扰，登录过期才提醒你，一键重新认证。

Microsoft Store：https://apps.microsoft.com/detail/9PK9DMKPH68Q
GitHub（便携版、源码，MIT 开源）：https://github.com/PeterShanxin/Remote-Commander-Tray

需要 Windows 10（商店版 2004+，便携版 1809+）或 Windows 11，Node.js（商店版需 22.12+）和官方 CLI（npm install -g @wonderwhy-er/desktop-commander），以及 Desktop Commander Remote 账号。"登录即启动"需在托盘菜单里勾选 Launch at sign-in。软件界面为英文。这是独立的免费开源工具，不是 Desktop Commander 官方产品。

短片用代码制作（Remotion），配乐用 CC0 真实乐器采样编排（Versilian Studios 的 VCSL、VSCO 2 CE），键盘声来自 unicaegames 的 Keyboard Soundpack 1（CC0）。
